## 📄 Repository Content

This repository covers **Part 2** of the C# & .NET fundamentals, focusing on
runtime behavior, memory management, and core language concepts.

### Topics Included
- Common Language Runtime (CLR)
- Class Loader & JIT Compiler
- Garbage Collector (GC)
- Managed vs Unmanaged Code
- Debug, Security, and Exception Engines
- Base Class Library (BCL)
- Common Type System (CTS)
- Namespaces & Project Structure
- EXE vs DLL
- Data Types & Precision
- Input / Output
- `ref` vs `out`
- Runtime Errors & Exception Handling
